### Resumen de la Sesión
Se llevó a cabo la reunión de revisión correspondiente al Avance 1 del proyecto. Durante la sesión se expuso el diagrama de bloques planteado 
inicialmente para la arquitectura monociclo junto con el análisis de las instrucciones obtenidas del código en C desensamblado.

Durante la evaluación, el profesor brindó retroalimentación técnica fundamental: indicó que la implementación monociclo actual presenta problemas de 
sincronización, ya que el PC, la memoria de instrucciones, el banco de registros y la memoria RAM funcionan dependientes del flanco positivo del reloj. 
Esto provoca un desfase entre la instrucción y las acciones que debe ejecutar dentro de un mismo pulso. Para corregir este desfase, el profesor instó 
migrar hacia una *Arquitectura Multiciclo*.

Asimismo, sugirió gestionar la bitácora mediante el flujo de trabajo de un repositorio en GitHub, donde las entregas e imprevistos queden registrados de 
forma continua. También sugirió trabajar mediante un documento detallado con las especificaciones del procesador en formato Markdown (`.md`) que deba 
actualizarse constantemente. Atendiendo de inmediato esta indicación, ese mismo día **David Rojas Castro** realizó la creación del repositorio oficial 
del grupo en GitHub.

### Acuerdos y Cambios Técnicos
1. Aprobación del cambio de diseño hacia una Arquitectura Multiciclo.
2. Adopción de GitHub como plataforma oficial para el control de versiones del código en Verilog, la bitácora y la documentación técnica.
3. Creación exitosa del repositorio en GitHub a cargo de David Rojas Castro.
